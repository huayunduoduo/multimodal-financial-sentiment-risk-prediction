# 多模态融合的金融风险预测模型

## 项目概述

本项目构建了一个多模态融合的金融风险预测模型，结合了LSTM处理时间序列数据和Transformer处理文本数据的优势。该模型可以根据金融文本数据预测对金融市场的影响，输出结果为[-1, 1]范围内的指标，其中0表示无影响，正数表示正向影响（上涨），负数表示负向影响（下跌），绝对值越大表示影响程度越大。

## 项目结构

```
srtp03/
├── dataset/
│   └── combined_features_unified_vector.csv  # 数据集文件（词向量）
├── data_loader.py                             # 数据加载和预处理
├── model.py                                   # 模型定义（LSTM+Transformer）
├── train.py                                   # 模型训练
├── predict.py                                 # 模型预测
├── requirements.txt                           # 项目依赖
└── README.md                                  # 项目说明文档
```

## 环境配置

首先安装项目所需的依赖库：

```bash
pip install -r requirements.txt
```

## 数据说明

数据集`combined_features_unified_vector.csv`包含了金融相关的词向量数据，每行代表一天的数据，第一列为日期，其余列为词向量特征（共3763个特征）。

## 使用步骤

### 1. 训练模型

运行`train.py`文件来训练模型：

```bash
python train.py
```

训练过程中，模型会自动保存最佳性能的模型权重到`saved_model.pth`，并生成损失曲线图表`loss_curve.png`。

### 2. 使用模型进行预测

训练完成后，可以运行`predict.py`文件来使用训练好的模型进行预测：

```bash
python predict.py
```

预测结果会显示在控制台，包括日期和对应的预测值。

## 模型架构

模型采用了多模态融合的设计思路：
- **LSTM部分**：用于处理时间序列数据，捕捉金融数据的时序特征
- **Transformer部分**：用于处理当前的特征数据，捕捉特征之间的复杂关系
- **融合层**：将两种模态的特征进行融合，提取更丰富的信息
- **输出层**：使用Tanh激活函数确保输出在[-1, 1]范围内

## 注意事项

1. 由于缺少真实的标签数据，当前模型使用了简化的标签生成方法，在实际应用中应该使用真实的金融影响指标作为标签。
2. 可以根据需要调整`train.py`中的参数来优化模型性能，如隐藏层维度、学习率、批次大小等。
3. 模型训练完成后，可以在`predict.py`中添加自定义的预测逻辑来满足特定需求。

## 结果解释

模型输出的预测值在[-1, 1]范围内：
- **接近1**：表示对金融市场有强烈的正向影响，预期上涨
- **接近0**：表示对金融市场影响较小，预期保持稳定
- **接近-1**：表示对金融市场有强烈的负向影响，预期下跌
