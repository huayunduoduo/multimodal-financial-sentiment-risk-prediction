# 多模态融合的金融风险预测模型报告

## 1. 项目概述

本项目旨在构建一个多模态融合的金融风险预测模型，通过融合时间序列特征和当前特征，预测金融风险的影响指标，输出范围为[-1,1]，其中负值表示负向影响，正值表示正向影响，0表示中性影响。

## 2. 数据说明

项目使用`combined_features_unified_vector.csv`数据集，该数据集包含：
- 日期字段（date）
- 3763个数值特征（词向量表示）
- 总数据量：从训练日志看，模型使用了足够的样本进行训练

数据处理方式：
- 将数据划分为训练集（80%）和测试集（20%）
- 构建时间序列特征：使用连续10天的特征作为时间序列输入
- 使用下一天的第一个特征作为标签的近似

## 3. 模型结构讲解

本项目的核心是`MultiModalFinancialModel`类，采用LSTM+Transformer的多模态融合架构，具体结构如下：

```
MultiModalFinancialModel(
  (lstm): LSTM(input_size=3763, hidden_size=64, batch_first=True)
  (transformer): TransformerEncoder(
    TransformerEncoderLayer(
      (self_attn): MultiheadAttention(
        (out_proj): Linear(in_features=3763, out_features=3763, bias=True)
      )
      (linear1): Linear(in_features=3763, out_features=512, bias=True)
      (linear2): Linear(in_features=512, out_features=3763, bias=True)
    )
  )
  (fusion_layer): Linear(in_features=64+3763, out_features=256, bias=True)
  (output_layer): Linear(in_features=256, out_features=1, bias=True)
  (tanh): Tanh()
)
```

模型主要由以下几个部分组成：

### 3.1 时间序列处理模块（LSTM）
- 输入：连续10天的特征序列（batch_size × seq_length × feature_dim）
- 作用：捕捉金融数据的时序依赖关系
- 输出：最后一个时间步的隐藏状态（batch_size × hidden_size）
- 参数：input_size=3763, hidden_size=64, batch_first=True

### 3.2 当前特征处理模块（Transformer）
- 输入：当前时间点的特征向量（batch_size × feature_dim）
- 作用：提取特征之间的复杂关系和交互影响
- 输出：经过自注意力机制处理后的特征向量（batch_size × feature_dim）
- 参数：nhead=8, dim_feedforward=512

### 3.3 特征融合层
- 输入：LSTM的输出和Transformer的输出的拼接
- 作用：将两种不同模态的特征进行有效融合
- 输出：融合后的特征向量（batch_size × 256）
- 参数：in_features=64+3763=3827, out_features=256

### 3.4 输出层
- 输入：融合后的特征向量
- 作用：将融合特征映射到最终预测值
- 输出：标准化的预测值（batch_size × 1），范围为[-1,1]
- 结构：Linear(in_features=256, out_features=1) + Tanh()

## 4. 模型构建思路

### 4.1 问题分析
金融风险预测是一个复杂的任务，需要考虑多种因素：
- 时间序列特性：金融数据具有明显的时序依赖性
- 高维特征：词向量特征维度高达3763维
- 非线性关系：特征之间存在复杂的非线性交互

### 4.2 技术选型理由
- **LSTM选择**：LSTM擅长处理时序数据，能够有效捕捉长期依赖关系，适合处理金融时间序列数据
- **Transformer选择**：Transformer通过自注意力机制可以捕获特征之间的复杂关系，尤其适合处理高维特征
- **多模态融合**：结合LSTM的时序建模能力和Transformer的特征关系建模能力，能够更全面地捕捉金融数据的复杂模式
- **Tanh输出层**：使用Tanh激活函数确保输出在[-1,1]范围内，符合项目要求

### 4.3 数据处理策略
- **时间序列构造**：使用连续10天的特征构建时序数据，平衡了计算效率和历史信息保留
- **标签生成**：使用下一天的特征作为标签的近似，简化了标签构建过程
- **数据划分**：采用80%/20%的训练集/测试集划分，确保模型泛化能力的评估

## 5. 模型调参过程

### 5.1 主要超参数设置
- **学习率**：0.001，使用Adam优化器
- **批量大小**：32，平衡了内存占用和训练稳定性
- **训练轮次**：50个epoch，足够让模型收敛
- **序列长度**：10，代表使用10天的历史数据
- **隐藏层大小**：LSTM的hidden_size=64，融合层的out_features=256
- **Transformer参数**：nhead=8, dim_feedforward=512

### 5.2 损失函数选择
使用均方误差（MSE）作为损失函数，适合回归任务，计算公式为：
```
l = torch.nn.MSELoss()
loss = l(pred, target)
```

### 5.3 优化器选择
使用Adam优化器，它结合了AdaGrad和RMSProp的优点，对学习率不敏感，收敛速度快：
```
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
```

### 7.1 性能评估

- **测试损失**：0.1335，模型在未见过的数据上表现一般

### 7.2 优势与不足

**优势**：
1. 多模态融合架构能够同时处理时序特征和当前特征
2. 输出范围控制在[-1,1]，符合项目要求
3. 模型结构清晰，易于扩展和改进

**不足**：
1. 存在过拟合现象，需要进一步优化（如添加正则化、增加数据量等）
2. 预测结果全部为负值，可能需要检查数据标签或特征处理方式
3. 模型复杂度较高，训练时间较长
